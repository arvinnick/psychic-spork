- Fixture: something that will be used in different functions but it doesn’t change.  
- You add fixtures as arguments.  
- “When pytest goes to run a test, it looks at the parameters in that test function’s signature, and then searches for fixtures that have the same names as those parameters. Once pytest finds them, it runs those fixtures, captures what they returned (if anything), and passes those objects into the test function as arguments.”  
- A test has 4 stages: arrange, act, assert, clean up. Fixture is to arrange as well as act.  
- The fixture can only take fixture as parameter  
- Parameters for fixture decorator:  
  - “Autouse” is when you write a fixture and all the tests will used it automatically.  
  - “Scope” will make the fixture resource available throughout the value. In the document, it is put in conftest file with the value of “module”.  
    - `function`: the default scope, the fixture is destroyed at the end of the test.  
    - `class`: the fixture is destroyed during teardown of the last test in the class.  
    - `module`: the fixture is destroyed during teardown of the last test in the module.  
    - `package`: the fixture is destroyed during teardown of the last test in the package where the fixture is defined, including sub-packages and sub-directories within it.  
    - `session`: the fixture is destroyed at the end of the test session.  
  - Put everything you need to use more than once in conftest.  
  - Use yield instead of return for tearing down. The test control will go from top to bottom on all the tests, running them one by one to the yield statements. Then, it will go backwards, running the codes after yield statements. It will be useful to tear down.  
  - A fixture function can get a “request” parameter which is exactly a request.  
  - We can also use markers to pass data to a fixture.  
  - A function can be returned in the fixture. This way, you will be able to use the fixture multiple times. This way, you will make a wrapper.  
  - You can also parametrize the function using “params” arg in the fixture decorator.  
  - Write one test, put @pytest.mark.parametrize on top of it with the test function. So it will run it for each parameter.
