Smart Kitchen Inventory & Predictive Replenishment System

1. Overview

This system is designed to eliminate human error in kitchen management by automating inventory tracking and ordering processes. By utilizing real-time weight data and historical consumption patterns, the system ensures that a kitchen never runs out of essential ingredients while simultaneously minimizing food waste.

2. The Core Concept: "The Predictive Brain"

The system operates on a feedback loop. It doesn't just look at what is missing; it learns from the past to predict the future. It treats the kitchen as a dynamic environment where variables (such as customer volume or supplier speed) are constantly changing.

Key Components

  • Mass-Based Tracking: Ingredients are placed on specialized scales. The system receives a constant stream of weight data, identifying exactly how much of a specific product (e.g., Salmon, Rice, Avocado) remains in real time.
  • Dynamic Coefficient Logic: Instead of relying on a static reorder point, the system uses a variable coefficient.
    • If the kitchen ends the week with excessive leftover stock (waste), the coefficient decreases.
    • If the kitchen runs out before the next delivery (shortage), the coefficient increases.
  • Latency Compensation: The system factors in lead time—the delay between placing an order and receiving goods. Orders are triggered early enough to cover expected consumption during that delivery window.

3. Optimization Goal

The primary objective of the algorithm is to achieve a Minimal Residual Average. Over a rolling three-month period, the system continuously adjusts ordering patterns until the remaining stock at the moment of the next delivery is as close as possible to the defined safety buffer without ever reaching zero.

4. Operational Flow

  1. Sensing: Scales transmit current ingredient weights in a simplified data format.
  2. Processing: The Predictive Brain compares current inventory levels against forecasted demand for the upcoming delivery cycle.
  3. Refining: The system evaluates waste logs. If ingredients were discarded, the ordering algorithm is penalized to reduce future over-ordering.
  4. Execution: When the safety threshold is breached (while accounting for delivery latency), the system automatically generates a replenishment request to the supply center.

Installation

For database initialization, run: 

python seed_db.py

Make sure the virtual environment is activated before running the command. Dockerization is planned for a future release.

The docs are standardized as localhost/redoc or localhost/docs.
